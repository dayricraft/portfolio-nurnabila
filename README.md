# Portofolio Resmi — Nur Nabila, S.Mat
**HR & People Analytics | Data Analysis | Leadership & Project Coordination**

Website portofolio resmi dan interaktif yang menampilkan profil **Sarjana Matematika dari IPB University** dengan keahlian dalam **HR Analytics, People Development**, pemrosesan **1.500+ data records (Python & Excel)**, serta kepemimpinan tim **PSDM (11 staf)** dan **Project Lead 65+ panitia**.

---

## 🌟 Fitur Utama Website

1. **Hero Profile & 4 Metrik Kunci**:
   - Foto profil resmi dengan badge verifikasi IPB University & S.Mat.
   - 4 kartu metrik pencapaian (11 Staf Evaluasi KPI & SDM, 65+ Panitia Project Lead Neomath, 1.500+ Record Data QC, BNSP Certified Data Scientist).
   - Tombol langsung untuk unduh CV (`Nur Nabila-CV.pdf`), WhatsApp, dan Email.

2. **3 Fokus Karir Utama**:
   - **HR & People Analytics**: Evaluasi kinerja & KPI SDM (11 staf PSDM Gumatika), 100+ arsip kepegawaian, pelatihan 7 Habits.
   - **Leadership & Project Coordination**: Project Lead 65+ panitia (Neomath 2025), Sekretaris Operasional SPIRIT lintas 10 divisi, alokasi sumber daya & pemodelan MILP.
   - **Data Analysis & Quality Control**: Audit 1.500+ data QC di PT Optima Solusi Indonesia, Machine Learning BNSP (XGBoost/Random Forest), publikasi riset FEM (Jurnal Techno.Com 2026).

3. **Showcase 7 Proyek Interaktif (Filter Kategori & Pop-up Modal)**:
   - **Data Quality Control & Audit System (PT Optima Solusi Indonesia)**: Validasi 1.500+ baris data.
   - **Incident Risk Prediction & EDA (Sertifikasi BNSP Data Scientist)**: Menampilkan visualisasi grafik EDA dan model machine learning.
   - **COPD Severity Classification (Skripsi Sarjana)**: PCA + Multinomial Logistic Regression.
   - **Nuclear Waste Route Optimization (Operations Research)**: Mixed Integer Linear Programming (MILP).
   - **Wi-Fi Signal Propagation Simulation**: Publikasi riset artikel ilmiah Finite Element Method (FEM) di Jurnal Techno.Com (DOI terintegrasi).
   - **Cryptographic Security Analysis**: Komparasi skema tanda tangan digital Rabin & Rabin-Williams.

4. **Dual Timeline Interaktif**:
   - Beralih mulus antara tab **Pengalaman Kerja (Data QC)** dan **Organisasi & Kepemimpinan** (5 posisi kepengurusan & kepanitiaan).

5. **Galeri 11 Sertifikat Terverifikasi & Integrasi Google Drive & Jurnal**:
   - Akses langsung ke folder Google Drive resmi dan DOI artikel jurnal.
   - 11 sertifikat lengkap (BNSP Data Scientist, Pelatihan SSMI, SKL Sarjana IPB, Ketua PSDM, Ketua Neomath, dll.) dengan tautan PDF.

6. **Matriks Keahlian Terstruktur**:
   - HR & People Analytics, Project Management Tools (Trello, Notion, Gantt Timelines).
   - Python ecosystem (Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn).
   - Spreadsheet lanjutan (Excel Pivot Tables, VLOOKUP, Data Validation).

## 🚀 Cara Menjalankan Secara Lokal

1. **Menggunakan `npm run dev`**:
   ```bash
   npm run dev
   ```
   Buka browser di: `http://localhost:3000`

2. **Membuka Langsung (Offline)**:
   - Cukup klik ganda (*double-click*) file `index.html`.

---

## 🌐 Cara Deploy ke Vercel (Gratis & Cepat)

1. Buat repositori baru di [GitHub](https://github.com) (misal: `nurnabila-portfolio`).
2. Unggah seluruh isi folder ini (`index.html`, `assets/`, `Nur Nabila-CV.pdf`, `vercel.json`) ke repositori GitHub tersebut.
3. Buka dashboard [Vercel](https://vercel.com/), pilih **Add New Project**, dan hubungkan dengan repositori GitHub Anda.
4. Klik **Deploy**. Website portofolio interaktif Anda langsung aktif secara global!
